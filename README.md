<h1 align="center">Django WebSocket Chat</h1>

<p align="center">
  A real-time messaging application built with Django Channels and WebSockets.
</p>

<h2>Features</h2>

<ul>
  <li>Real-time communication</li>
  <li>WebSocket connections</li>
  <li>Django Channels integration</li>
  <li>In-memory channel layer for development</li>
</ul>
